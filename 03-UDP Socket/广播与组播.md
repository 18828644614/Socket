# 广播与组播

## 学习目标

- 区分单播、广播和组播，以及它们各自把 UDP 数据发给谁。
- 理解广播地址为什么依赖子网掩码，且通常不能跨路由器。
- 在 Windows 上使用 `SO_BROADCAST` 发送广播，并用 `IP_ADD_MEMBERSHIP` 加入 IPv4 组播组。
- 在 Linux/WSL2 上运行等价程序，理解两种平台的主要差异。
- 从端口、防火墙、网卡和虚拟网络方向排查收不到数据报的问题。

## 1. 先建立直觉：数据可以交给谁

前面使用的 `sendto()` 通常把一份 UDP 数据报发给一个明确的 `IP:端口`，这叫**单播**。广播与组播同样使用 UDP 和 `sendto()`；区别主要是目标 IP 的含义。

```text
单播：  一台发送者  ----------------------> 一台指定主机
广播：  一台发送者  ----------------------> 同一局域网中的所有主机
组播：  一台发送者  ----------------------> 已加入同一组的主机
```

| 方式 | 目标是谁 | 例子 | 接收者需要做什么 | 常见用途 |
| --- | --- | --- | --- | --- |
| 单播 | 一台具体主机 | `192.168.1.20:9000` | 在端口上接收 | 客户端请求服务端 |
| 广播 | 一个局域网中的所有主机 | `192.168.1.255:9002` | 在端口上接收 | 局域网设备发现 |
| 组播 | 主动订阅该组的主机 | `239.255.0.1:9003` | 加入组，再接收 | 状态通知、行情分发 |

广播像在教室里喊话，教室中所有人都会听到。组播像给一个兴趣小组发通知，只有加入小组的人收到。两者都不是“可靠群发”：UDP 仍可能丢包、重复或乱序。

> 本章只讨论 IPv4。IPv6 不支持广播；IPv6 的一对多通信使用组播。

## 2. 广播

### 2.1 广播地址为什么常以 `.255` 结尾

IPv4 地址分为网络部分与主机部分，子网掩码决定边界。**定向广播地址**就是把一个子网的所有主机位设置为 `1`：

```text
IP 地址：       192.168.10. 42
子网掩码：      255.255.255.  0    （/24，最后 8 位是主机位）
子网广播地址：  192.168.10.255
```

因此，`/24` 网络中广播地址通常以 `.255` 结尾，但这不是通用规律。例如 `192.168.10.0/23` 覆盖两个 `/24`，其广播地址是 `192.168.11.255`。不要凭直觉猜测广播地址。

在 Windows PowerShell 中查看本机网卡的 IPv4 地址和前缀长度：

~~~powershell
Get-NetIPAddress -AddressFamily IPv4 |
    Where-Object { $_.IPAddress -notlike '127.*' } |
    Format-Table InterfaceAlias, IPAddress, PrefixLength
~~~

若本机为 `192.168.10.42`、前缀长度为 `24`，才可以得出广播地址是 `192.168.10.255`。

### 2.2 两种常见广播地址

| 地址 | 名称 | 范围 | 用途 |
| --- | --- | --- | --- |
| `255.255.255.255` | 有限广播 | 直接相连网络，路由器不会转发 | 初次同机实验 |
| 例如 `192.168.10.255` | 定向广播 | 指定 IPv4 子网 | 已知网段时更明确 |

广播通常不能经过路由器。企业 Wi-Fi、访客网络、VPN、VLAN 和虚拟网络也可能限制广播，所以 `sendto()` 成功只表示本机内核接受了数据，并不表示其他机器已经收到。

### 2.3 `SO_BROADCAST` 的作用

系统要求发送程序显式开启 `SO_BROADCAST`，避免普通程序意外向整个局域网发包。它是**发送端**选项，接收端一般不需要设置：

~~~c
BOOL enabled = TRUE;
if (setsockopt(sock, SOL_SOCKET, SO_BROADCAST,
               (const char *)&enabled, sizeof(enabled)) == SOCKET_ERROR) {
    /* 未设置时，向广播地址的 sendto() 通常会失败。 */
}
~~~

### 2.4 Windows 优先：广播接收者

保存为 `udp_broadcast_receiver_win.c`。它绑定 `0.0.0.0:9002`，即接收送到本机任一 IPv4 网卡、端口为 `9002` 的 UDP 数据报。

~~~c
#include <winsock2.h>
#include <ws2tcpip.h>
#include <stdio.h>

#pragma comment(lib, "Ws2_32.lib")

#define PORT 9002
#define BUFFER_SIZE 1024

int main(void) {
    WSADATA wsa_data;
    SOCKET receiver;
    struct sockaddr_in local_addr = {0};

    if (WSAStartup(MAKEWORD(2, 2), &wsa_data) != 0) {
        printf("WSAStartup failed: %d\n", WSAGetLastError());
        return 1;
    }
    receiver = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    if (receiver == INVALID_SOCKET) {
        printf("socket failed: %d\n", WSAGetLastError());
        WSACleanup(); return 1;
    }
    local_addr.sin_family = AF_INET;
    local_addr.sin_port = htons(PORT);
    local_addr.sin_addr.s_addr = htonl(INADDR_ANY); /* 任一 IPv4 网卡 */
    if (bind(receiver, (const struct sockaddr *)&local_addr,
             sizeof(local_addr)) == SOCKET_ERROR) {
        printf("bind failed: %d\n", WSAGetLastError());
        closesocket(receiver); WSACleanup(); return 1;
    }

    printf("Waiting for UDP broadcast on port %d...\n", PORT);
    for (;;) {
        char buffer[BUFFER_SIZE];
        struct sockaddr_in sender_addr = {0};
        int sender_len = sizeof(sender_addr); /* 每轮都要重置容量 */
        int received = recvfrom(receiver, buffer, BUFFER_SIZE - 1, 0,
                                (struct sockaddr *)&sender_addr, &sender_len);
        if (received == SOCKET_ERROR) {
            printf("recvfrom failed: %d\n", WSAGetLastError());
            continue;
        }
        buffer[received] = '\0'; /* 仅为了按 C 字符串打印文本 */
        printf("received from port %u: %s\n",
               (unsigned int)ntohs(sender_addr.sin_port), buffer);
    }
}
~~~

### 2.5 Windows 优先：广播发送者

保存为 `udp_broadcast_sender_win.c`。首次实验用有限广播地址；如果确定局域网子网为 `192.168.10.0/24`，可把宏改为 `"192.168.10.255"`。

~~~c
#include <winsock2.h>
#include <ws2tcpip.h>
#include <stdio.h>
#include <string.h>

#pragma comment(lib, "Ws2_32.lib")

#define PORT 9002
#define BROADCAST_IP "255.255.255.255"

int main(void) {
    WSADATA wsa_data;
    SOCKET sender;
    struct sockaddr_in target = {0};
    BOOL enabled = TRUE;
    const char message[] = "hello from Windows broadcast";

    if (WSAStartup(MAKEWORD(2, 2), &wsa_data) != 0) return 1;
    sender = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    if (sender == INVALID_SOCKET) { WSACleanup(); return 1; }
    if (setsockopt(sender, SOL_SOCKET, SO_BROADCAST,
                   (const char *)&enabled, sizeof(enabled)) == SOCKET_ERROR) {
        printf("setsockopt(SO_BROADCAST) failed: %d\n", WSAGetLastError());
        closesocket(sender); WSACleanup(); return 1;
    }
    target.sin_family = AF_INET;
    target.sin_port = htons(PORT);
    if (inet_pton(AF_INET, BROADCAST_IP, &target.sin_addr) != 1) {
        printf("Invalid broadcast address.\n");
        closesocket(sender); WSACleanup(); return 1;
    }
    if (sendto(sender, message, (int)strlen(message), 0,
               (const struct sockaddr *)&target, sizeof(target)) == SOCKET_ERROR) {
        printf("sendto failed: %d\n", WSAGetLastError());
    } else {
        printf("sent to %s:%d\n", BROADCAST_IP, PORT);
    }
    closesocket(sender); WSACleanup();
    return 0;
}
~~~

编译和运行：

~~~powershell
# MinGW-w64
gcc -Wall -Wextra -g udp_broadcast_receiver_win.c -o udp_broadcast_receiver_win.exe -lws2_32
gcc -Wall -Wextra -g udp_broadcast_sender_win.c -o udp_broadcast_sender_win.exe -lws2_32

# 窗口 A，先启动接收者
.\udp_broadcast_receiver_win.exe

# 窗口 B，再发送
.\udp_broadcast_sender_win.exe
~~~

Visual Studio Developer PowerShell 可使用 `cl /W4 /Zi udp_broadcast_receiver_win.c ws2_32.lib`，发送者同理。

若另一台可信局域网机器收不到，允许接收端的 UDP `9002` 入站流量，而不是关闭整个防火墙：

~~~powershell
New-NetFirewallRule -DisplayName "UDP broadcast demo 9002" `
    -Direction Inbound -Protocol UDP -LocalPort 9002 -Action Allow
~~~

实验结束后删除规则：`Remove-NetFirewallRule -DisplayName "UDP broadcast demo 9002"`。

### 2.6 Linux/WSL2 等价广播示例

Linux 的流程相同，主要区别是没有 `WSAStartup()`，Socket 类型为 `int`，关闭时使用 `close()`。接收端核心代码：

~~~c
#include <arpa/inet.h>
#include <netinet/in.h>
#include <stdio.h>
#include <sys/socket.h>
#include <unistd.h>

int main(void) {
    int sock = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    struct sockaddr_in local = {0};
    char buffer[1024];
    if (sock < 0) { perror("socket"); return 1; }
    local.sin_family = AF_INET;
    local.sin_port = htons(9002);
    local.sin_addr.s_addr = htonl(INADDR_ANY);
    if (bind(sock, (struct sockaddr *)&local, sizeof(local)) < 0) {
        perror("bind"); close(sock); return 1;
    }
    for (;;) {
        ssize_t n = recvfrom(sock, buffer, sizeof(buffer) - 1, 0, NULL, NULL);
        if (n < 0) { perror("recvfrom"); continue; }
        buffer[n] = '\0';
        printf("received: %s\n", buffer);
    }
}
~~~

保存为 `udp_broadcast_sender_linux.c`。发送端除错误处理和关闭方式外，与 Windows 版本相同：

~~~c
#include <arpa/inet.h>
#include <netinet/in.h>
#include <stdio.h>
#include <string.h>
#include <sys/socket.h>
#include <unistd.h>

int main(void) {
    int sock = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    struct sockaddr_in target = {0};
    const char message[] = "hello from Linux broadcast";
int enabled = 1;
    if (sock < 0) { perror("socket"); return 1; }
    if (setsockopt(sock, SOL_SOCKET, SO_BROADCAST, &enabled, sizeof(enabled)) < 0) {
        perror("SO_BROADCAST"); close(sock); return 1;
    }
    target.sin_family = AF_INET;
    target.sin_port = htons(9002);
    inet_pton(AF_INET, "255.255.255.255", &target.sin_addr);
    if (sendto(sock, message, strlen(message), 0,
               (struct sockaddr *)&target, sizeof(target)) < 0) {
        perror("sendto"); close(sock); return 1;
    }
    close(sock);
    return 0;
}
~~~

./udp_broadcast_receiver_linux

## 3. 组播

### 3.1 组播地址表示一个“组”，不是一台主机

IPv4 组播地址范围为 `224.0.0.0` 到 `239.255.255.255`。练习使用 `239.255.0.1:9003`；`239.0.0.0/8` 是组织内部可规划的管理范围地址。不要随意使用 `224.0.0.x`，其中很多地址被网络控制协议保留。

```text
发送者  sendto(message, 239.255.0.1:9003)
                         |
                         +--> 已加入组的接收者 A
                         +--> 已加入组的接收者 B
                         +--> 已加入组的接收者 C

未加入此组的主机不会因为端口也是 9003 就自动收到。
```

### 3.2 `bind()` 和“加入组”是两件事

组播接收端顺序是：

```text
socket() -> bind(0.0.0.0:9003) -> IP_ADD_MEMBERSHIP -> recvfrom()
```

- `bind()` 表示“在本机端口 `9003` 接收 UDP 数据”。
- `IP_ADD_MEMBERSHIP` 表示“请让某块本机网卡加入 `239.255.0.1`，并把该组的包交给这个 Socket”。

`struct ip_mreq` 的 `imr_interface` 用于选择本机网卡。填 `INADDR_ANY` 时系统选择默认网卡，初学实验足够；有 Wi-Fi、以太网、VPN 或虚拟网卡时，最好填入明确的本机 IPv4 地址。

组播发送端常用两个选项：

| 选项 | 含义 | 本章值 |
| --- | --- | --- |
| `IP_MULTICAST_TTL` | 最多经过多少个路由跳数 | `1`，限制在本地网络范围 |
| `IP_MULTICAST_LOOP` | 本机发出的包是否交给本机加入该组的 Socket | `1`，方便同机实验 |

TTL 不是安全机制。组播不自动加密或认证，不能把它收到的数据直接当作可信命令执行。

### 3.3 Windows 优先：组播接收者

保存为 `udp_multicast_receiver_win.c`：

~~~c
#include <winsock2.h>
#include <ws2tcpip.h>
#include <stdio.h>

#pragma comment(lib, "Ws2_32.lib")

#define PORT 9003
#define GROUP_IP "239.255.0.1"

int main(void) {
    WSADATA wsa_data;
    SOCKET receiver;
    struct sockaddr_in local = {0};
    struct ip_mreq membership = {0};

    if (WSAStartup(MAKEWORD(2, 2), &wsa_data) != 0) return 1;
    receiver = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    if (receiver == INVALID_SOCKET) { WSACleanup(); return 1; }

    local.sin_family = AF_INET;
    local.sin_port = htons(PORT);
    local.sin_addr.s_addr = htonl(INADDR_ANY);
    if (bind(receiver, (const struct sockaddr *)&local, sizeof(local)) == SOCKET_ERROR) {
        printf("bind failed: %d\n", WSAGetLastError());
        closesocket(receiver); WSACleanup(); return 1;
    }
    if (inet_pton(AF_INET, GROUP_IP, &membership.imr_multiaddr) != 1) {
        printf("Invalid multicast group.\n");
        closesocket(receiver); WSACleanup(); return 1;
    }
    /* 多网卡环境可改为本机指定网卡，例如 192.168.10.42。 */
    membership.imr_interface.s_addr = htonl(INADDR_ANY);
    if (setsockopt(receiver, IPPROTO_IP, IP_ADD_MEMBERSHIP,
                   (const char *)&membership, sizeof(membership)) == SOCKET_ERROR) {
        printf("IP_ADD_MEMBERSHIP failed: %d\n", WSAGetLastError());
        closesocket(receiver); WSACleanup(); return 1;
    }

    printf("Joined %s:%d\n", GROUP_IP, PORT);
    for (;;) {
        char buffer[1024];
        int received = recvfrom(receiver, buffer, sizeof(buffer) - 1, 0, NULL, NULL);
        if (received == SOCKET_ERROR) { printf("recvfrom failed\n"); continue; }
        buffer[received] = '\0';
        printf("received: %s\n", buffer);
    }
}
~~~

### 3.4 Windows 优先：组播发送者

保存为 `udp_multicast_sender_win.c`：

~~~c
#include <winsock2.h>
#include <ws2tcpip.h>
#include <stdio.h>
#include <string.h>

#pragma comment(lib, "Ws2_32.lib")

#define PORT 9003
#define GROUP_IP "239.255.0.1"

int main(void) {
    WSADATA wsa_data;
    SOCKET sender;
    struct sockaddr_in group = {0};
    const char message[] = "hello from Windows multicast";
    int ttl = 1, loop_enabled = 1;

    if (WSAStartup(MAKEWORD(2, 2), &wsa_data) != 0) return 1;
    sender = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    if (sender == INVALID_SOCKET) { WSACleanup(); return 1; }
    if (setsockopt(sender, IPPROTO_IP, IP_MULTICAST_TTL,
                   (const char *)&ttl, sizeof(ttl)) == SOCKET_ERROR ||
        setsockopt(sender, IPPROTO_IP, IP_MULTICAST_LOOP,
                   (const char *)&loop_enabled, sizeof(loop_enabled)) == SOCKET_ERROR) {
        printf("setsockopt failed: %d\n", WSAGetLastError());
        closesocket(sender); WSACleanup(); return 1;
    }
    group.sin_family = AF_INET;
    group.sin_port = htons(PORT);
    if (inet_pton(AF_INET, GROUP_IP, &group.sin_addr) != 1) {
        closesocket(sender); WSACleanup(); return 1;
    }
    if (sendto(sender, message, (int)strlen(message), 0,
               (const struct sockaddr *)&group, sizeof(group)) == SOCKET_ERROR) {
        printf("sendto failed: %d\n", WSAGetLastError());
    } else {
        printf("sent multicast to %s:%d\n", GROUP_IP, PORT);
    }
    closesocket(sender); WSACleanup();
    return 0;
}
~~~

~~~c

~~~

其中地址必须属于本机，而不是组地址或远程电脑地址。发送端也可通过 `IP_MULTICAST_IF` 指定出站网卡，但先验证默认网卡路径，再增加这个选项。

### 3.5 Linux/WSL2 等价组播示例

Linux 接收端的关键逻辑与 Windows 相同，差异仅在 API 包装：

~~~c
#include <arpa/inet.h>
#include <netinet/in.h>
#include <stdio.h>
#include <sys/socket.h>
#include <unistd.h>

int main(void) {
    int sock = socket(AF_INET, SOCK_DGRAM, IPPROTO_UDP);
    struct sockaddr_in local = {0};
    struct ip_mreq group = {0};
    if (sock < 0) { perror("socket"); return 1; }
    local.sin_family = AF_INET;
    local.sin_port = htons(9003);
    local.sin_addr.s_addr = htonl(INADDR_ANY);
    if (bind(sock, (struct sockaddr *)&local, sizeof(local)) < 0) {
        perror("bind"); close(sock); return 1;
    }
    inet_pton(AF_INET, "239.255.0.1", &group.imr_multiaddr);
    group.imr_interface.s_addr = htonl(INADDR_ANY);
    if (setsockopt(sock, IPPROTO_IP, IP_ADD_MEMBERSHIP,
                   &group, sizeof(group)) < 0) {
        perror("IP_ADD_MEMBERSHIP"); close(sock); return 1;
    }
    printf("Joined 239.255.0.1:9003\n");
    for (;;) {
        char buffer[1024];
        ssize_t n = recvfrom(sock, buffer, sizeof(buffer) - 1, 0, NULL, NULL);
        if (n < 0) { perror("recvfrom"); continue; }
        buffer[n] = '\0';
        printf("received: %s\n", buffer);
    }
}
~~~

## 4. 使用限制

| 问题 | 广播 | 组播 |
| --- | --- | --- |
| 收件人 | 子网中所有主机 | 加入指定组的主机 |
| 发送端关键设置 | `SO_BROADCAST` | 常用 `IP_MULTICAST_TTL` |
| 接收端关键设置 | `bind()` | `bind()` 后 `IP_ADD_MEMBERSHIP` |
| 跨路由器 | 通常不能 | 取决于路由器和网络配置 |
| 适合场景 | 受控小局域网中的发现 | 一对多状态发布 |

组播相较广播更节省接收端处理，但网络设备不一定已配置组播转发。两者都不适合传输敏感数据或执行未经验证的远程命令；生产协议仍需认证、完整性校验、限速和超时处理。

## 实践

1. 在 Windows 同机运行广播接收者与发送者，确认接收者打印消息。
2. 确认自己的子网掩码后，把广播目标替换为正确的定向广播地址；只在可信局域网测试。
3. 先启动组播接收者，再发送，解释为什么 `bind()` 之后还必须调用 `IP_ADD_MEMBERSHIP`。
4. 将组播发送端的 `loop_enabled` 改为 `0`，比较同机接收结果并解释其作用。
5. 有多张网卡时，为 `membership.imr_interface` 指定一张本机网卡地址并记录变化。
6. 在 Linux/WSL2 运行等价程序，比较初始化、错误处理和关闭 Socket 的差异。

## 5. 排查命令

Windows：

~~~powershell
Get-NetUDPEndpoint -LocalPort 9002,9003
netstat -ano -p udp
~~~

Linux/WSL2：

~~~bash
ss -u -a -n | grep -E '9002|9003'
~~~

| 现象 | 常见原因与处理 |
| --- | --- |
| 广播 `sendto()` 失败 | 未设置 `SO_BROADCAST`，或广播地址不正确。 |
| 本机能收、另一台机器不能收 | 两机不在同一 VLAN、Wi-Fi 客户端隔离、防火墙未放行 UDP 端口。 |
| 组播接收者一直等待 | 未调用 `IP_ADD_MEMBERSHIP`、组/端口不一致、默认网卡选错。 |
| `bind()` 失败 | 端口被旧程序占用；关闭旧程序或双方一起换端口。 |
| WSL2 与局域网机器互相收不到 | WSL2 虚拟网络的广播/组播转发依赖当前网络模式；先做同环境测试。 |
| 多个接收者监听同一端口失败 | `SO_REUSEADDR` 在 Windows 与 Linux 语义不同，初学阶段先只运行一个接收者。 |

不要通过关闭全部防火墙来排查。只对实验端口创建临时的 UDP 入站规则，并在实验结束后删除。
