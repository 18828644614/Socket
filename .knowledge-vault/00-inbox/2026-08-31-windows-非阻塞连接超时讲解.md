# Session: Windows 非阻塞连接超时讲解

## Summary

本次会话围绕 Windows Winsock 的非阻塞 `connect()` 超时实现展开。已将面向初学者的解释追加到仓库中的“超时、断线与异常”章节，并说明 `ioctlsocket()`、`fd_set`/`select()` 与 `getsockopt(SO_ERROR)` 的职责边界。

## Outcomes

- 解释 `ioctlsocket(sock, FIONBIO, &nonblocking)`：非零值开启非阻塞，零值恢复阻塞。
- 解释 `select()`：在限定时间内等待 Socket 的可写或异常状态；返回可写不等于连接成功。
- 解释 `fd_set`、`FD_ZERO()`、`FD_SET()`：准备交给 `select()` 的观察集合。
- 解释 `getsockopt(..., SO_ERROR, ...)`：查询 `connect()` 的最终错误；区分查询函数失败与连接本身失败。
